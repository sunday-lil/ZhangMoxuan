# 《流浪地球 2》系统界面参考与重建说明

> 记录 2026-11 对影片 UI 的检索、拆解，以及本项目 v2.0.0 视觉重建的对应关系。
> 本文只引用公开文章与截图链接，不包含电影原片截图；项目内的 `Assets/sim-room.png`、`Assets/sim-father.png` 为程序生成的原创近似素材。

- 官方/半官方 FUI 项目与 550W 道具照片

## 2. 影片 UI 的硬性规范

《流浪地球 2》制作手记与相关访谈给出了明确规范（见 [制作手记开箱](https://www.gmcllp.cn/617.html)、[机核美术解析](https://www.gcores.com/articles/166067)）：

| 项目 | 规范 |
|------|------|
| 中文字体 | 思源黑体 |
| 英文字体 | Rajdhani |
| 字号 | 按屏幕尺寸与观看距离确定，刻意控制版式密度 |
| 整体色 | 深灰色系，不是蓝黑/纯黑 |
| 跳色 | 红色、中黄、亮白 |
| 慎用 | 绿色、蓝色作为大面积跳色（会影响后期抠像） |
| 边框 | 避免斜线构成，以正交矩形、细线、分组框为主 |

因此影片里的界面并不是“霓虹红 + 斜线网格 + 大量留白”的通用科幻 HUD，而是**接近航空/军工控制台的深灰底、白字、红/黄告警、极高信息密度**。

## 3. 四类关键界面拆解

### 3.1 UEG 作战室 / 雷达监控

参考：机核文章中联合政府雷达屏、巴黎飞控中心复刻 UI（[机核机组](https://www.gcores.com/talks/1013408)）。

- 黑色/深灰底，白色细线，红色只用于告警与敌我识别
- 距离环、方位刻度、扫描扇区、目标接触点与短标签
- 左侧目标列表、右侧程序列表、顶部多排标签页
- 信息密度高，几乎不出现大面积纯装饰留白

### 3.2 550A 数字生命模拟

参考：机核文章中 550A 模拟图丫丫的剧照。

- 主体是**摄像头画面**，UI 直接叠在画面上
- 顶部：资源占用、内存占用、告警、神经元映射
- 左侧：数字行为构建、语音合成、情绪匹配、场景参数
- 右侧：另一路摄像头画面、识别输出、置信度
- 底部：暂停键 + `00:01:45` 时间码 + 进度条 + 内存容量
- 字体以白色小号无衬线为主，红色只用于倒计时和危险提示

### 3.3 太空电梯 / 密钥闸机

参考：太空电梯闸机屏（`CABIN-04 PASS` 场景）。

- 黑色底 + 琥珀色主色，绿色只用于 PASS
- 正交虚线、斜线填充的安全检查区域、状态框
- 大号状态字与小型设备表并存

### 3.4 550W / MOSS 硬件

参考：550W 道具照片与 MOSS 之眼特写。

- 白色/浅灰金属外壳，黑色镜筒，红色虹膜
- 外壳有分缝、螺栓、铭牌、状态灯
- 不是悬浮在黑色背景上的红色发光圆环

## 4. 从旧版到 v2.0.0 的映射

| 旧版 | v2.0.0 |
|------|--------|
| 深蓝黑 + 大面积赤红 | 深灰 `#121212` / `#1A1A1A` + 红、中黄、亮白 |
| 大量等宽字体 | 中文微软雅黑（思源黑体系统替代）+ 内置 Rajdhani |
| 圆角卡片、斜线量子连线 | 0 圆角、正交分组框、矩阵扫描线 |
| 世界地图点阵 + 斜向连线 | 距离环 / 方位刻度 / 扫描扇区 / 接触点列表 |
| 数字生命红蓝球卡片 | 550A 模拟：左侧参数、右侧摄像头、底部倒计时/暂停 |
| 悬浮红色 MOSS 之眼 | 白色金属外壳 + 黑色镜筒 + 红色虹膜 |
| 稀疏的页面留白 | 顶部 KPI、表格式数据、状态栏、事件日志 |

- 未使用任何电影原片截图作为应用素材；数字生命画面为程序生成的近似场景，用来还原版式与信息层级。

- 550A 场景是“界面复刻”而非画面复刻；真实影片中的摄像头画面、演员与场景不进入仓库。
